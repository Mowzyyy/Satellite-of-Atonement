# Satellite of Atonement 
*A Game by Mowz and the Cigma Gaming Team*

**In the Aegis Star System, a hidden prince must unite unlikely companions across three planets to overthrow a tyrannical pretender and an alien god, blending sword-and-sorcery with space cowboys, lasers, spaceships, and adroids in a fantastical opera.**
